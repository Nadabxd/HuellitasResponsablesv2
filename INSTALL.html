Guía de Instalación

info Antes de comenzar: Asegúrate de tener XAMPP instalado y funcionando.

1 Verificar XAMPP

Inicia Apache y MySQL desde el Panel de Control de XAMPP.

✓ Apache debe estar en estado "Running"
✓ MySQL debe estar en estado "Running"

2 Ubicar el Proyecto

Este proyecto debe estar en la carpeta htdocs de XAMPP:

C:\xampp\htdocs\HuellasResponsables\

3 Crear la Base de Datos

  1. Abre phpMyAdmin: http://localhost/phpmyadmin
  2. Haz clic en "Nueva" en el menú izquierdo
  3. Importa el archivo database.sql ubicado en la raíz del proyecto
  4. Alternativamente, copia y pega el contenido de database.sql en la pestaña SQL

4 Configurar la Conexión

El archivo config/conexion.php ya tiene la configuración por defecto de XAMPP:

Host: localhost
Usuario: root
Contraseña: (vacío)
Base de datos: huellas_responsables

Si tu configuración es diferente, edita este archivo.

5 Permisos de Carpetas

Asegúrate de que la carpeta de uploads tenga permisos de escritura:

assets/img/uploads/

6 Acceder al Sistema

Una vez completados los pasos anteriores, accede a:

login Ir al Login

O visita: http://localhost/HuellasResponsables/auth/login.php

vpn_key Credenciales de Prueba

help Solución de Problemas

  • Error de conexión a BD: Verifica que MySQL esté corriendo y las credenciales en config/conexion.php
  • Página en blanco: Activa la visualización de errores de PHP en php.ini
  • No carga imágenes: Verifica permisos de la carpeta assets/img/uploads/
  • Error 404: Verifica que el proyecto esté en htdocs y la URL sea correcta
